# 画像生成プロンプト（ChatGPT用）

合計 **20枚**（必須11枚＋推奨9枚）

| 区分 | 枚数 | サイズ（ChatGPTで指定） | 使う場所 |
|---|---|---|---|
| Hero | 1 | 横長 3:2（1536×1024） | ファーストビュー／SNS共有画像（OGP）にも流用 |
| カテゴリ | 10 | 正方形（1024×1024） | 「買う予定だったものありませんか？」のカテゴリタイル |
| シーン | 9 | 横長 3:2（1536×1024） | 「毎日使うものを補充するなら」など各セクションの見出し画像 |

## 使い方

1. ChatGPTで新しいチャットを開き、最初に下の「共通スタイル」を送る
2. **同じチャットのまま**、各プロンプトを1つずつ送る（統一感が出ます）
3. 保存するときのファイル名は、各プロンプトの見出しにある名前（例：`hero.png`）
4. できた画像をこのチャットに添付してください。圧縮・配置・表示確認はこちらで行います

> 気に入らない画像は「もう少し生活感を出して」「もっと引きで」「色を落ち着かせて」などと追加で頼むと調整できます。
> 文字やロゴが入ってしまった画像は使わないでください（商標・誤認のリスクがあります）。

---

## 共通スタイル（最初に1回送る）

```
これから、日本の買い物ガイドサイトで使う写真風の画像を20枚作ります。全ての画像に次のスタイルを適用してください。

・日本の一般的な家庭の室内で、自然光で撮った写真のような質感
・35mmフィルムで撮ったような、やわらかい粒子感と落ち着いた自然な色（彩度は控えめ）
・少しだけ生活感がある。完璧に整いすぎた配置や左右対称は避け、ものは少し無造作に置く
・背景は生成り・オフホワイトの壁、明るい木の家具や床、リネンなど
・広告っぽいCG感、テカテカした質感、強すぎるボケ、ドラマチックな照明は使わない
・文字、ロゴ、ブランド名、商品名は一切入れない。パッケージは全て無地（白・生成り・淡い水色・淡い緑・淡い黄色など）
・段ボールは無地の茶色い箱にし、ロゴや矢印マークは入れない
・人物の顔と手は写さない
```

### `hero.png`（横長 3:2）
```
玄関を上がったところの明るい木の床に、届いたばかりの無地の段ボール箱がふたを開けて置いてある。箱の中と周りに、トイレットペーパーのまとめ買いパック、2Lの水のペットボトル2〜3本、洗濯洗剤の詰め替えパウチ、ボックスティッシュが少し無造作に置かれている。床には、チェックボックスの四角だけが縦に並んだ白いメモ用紙と鉛筆（文字は書かない）。午前中のやわらかい自然光が横から差し込む。生成りの壁。少し上から見下ろす角度。被写体は画面の中央からやや下に配置し、左右に少し余白を残す。横長3:2。
```

## 補足

- **商品カードの画像には使いません。** 実際の商品画像は、規約上Amazonが提供する画像（SiteStripe等のURL）を使う必要があるためです。生成画像は、Hero・カテゴリ・シーンなどサイトの雰囲気づくりの部分だけに使います。
- **SNS共有画像（OGP）** は Hero 画像を切り抜き、サイト名とコピーを重ねてこちらで作成します。
- セールごとに雰囲気を変えたい場合は、Hero だけ差し替えるのがおすすめです（例：ブラックフライデーは夕方の光で落ち着いたトーンに）。
